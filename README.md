# 📺 Телетекст Плеер

> Веб-архив телетекста — атмосферный ретро-плеер для просмотра HTML-страниц телетекста

---

## ✨ Возможности

- **Просмотр страниц** — номера от 100 до 999, навигация стрелками и кнопками
- **Подстраницы** — автоматическое определение и переключение между подстраницами
- **Автолистание** — кнопка play/pause и ползунок скорости, как на настоящем телевизоре
- **Превью** — генерация PNG-миниатюр 250×250 через Puppeteer + Sharp
- **Редактирование карточек** — название, описание, логотип для каждого архива
- **Менеджер файлов** — загрузка, удаление, переименование, перемещение файлов и папок

---

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Разработка (авторестарт при изменениях)
npm run dev

# Продакшн
npm start
```

Порт задаётся в `.env`:

```env
HTTP_PORT=3232
```

По умолчанию — `3000`.

---

## 🛠 Стек

| Технология | Назначение |
|---|---|
| Node.js + Express 4 | HTTP-сервер |
| EJS | Шаблонизатор |
| Puppeteer + Sharp | Генерация PNG-превью |
| Multer | Загрузка файлов |
| dotenv | Конфигурация |

---

## 📁 Структура контента

```
teletext/
└── <архив>/
    ├── <номер>.html    ← страница телетекста (100–999)
    ├── <номер>.png     ← превью 250×250
    ├── title.txt       ← название архива
    ├── description.txt ← описание
    └── logo.svg / logo.png
```

Папка `teletext/` не включена в репозиторий (`.gitignore`).

## 📂 Структура проекта

```
server.js                   — точка входа
lib/
  utils.js                  — logAction, isValidPath
  thumbnails.js             — генерация превью
middleware/
  errorHandler.js           — AppError, asyncHandler, errorHandler
  upload.js                 — multer
  security.js               — CSP и security headers
routes/
  index.js                  — GET /
  folder.js                 — GET /folder/*
  page.js                   — GET /page/*/:page
  card.js                   — редактирование карточек
  manager.js                — менеджер файлов
  thumbnails.js             — генерация превью
views/                      — EJS-шаблоны
public/                     — статика (CSS, изображения)
```
